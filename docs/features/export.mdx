# Complete Data Export & Portability

Your research belongs to you—**period**. We believe in total data ownership and zero vendor lock-in. Whether you need to publish a finished narrative, print a PDF report, back up your raw media, or create a full database restore point, export is always instant, complete, and processed 100% locally on your computer.

---

### 🛡️ Private & Selective Sharing
Before generating any export, you can toggle **Confidentiality Filters** to automatically sanitize your output—excluding living relatives, private notes, or sensitive records with a single click.

---

## What Gets Exported by Entity Type

When you export an individual entity or topic, the app packages all associated metadata and media into a clean, portable bundle:

| Entity Type | Export Package Contents |
| :--- | :--- |
| **👤 Person** | Biography note, linked records, and primary media attachments. |
| **📍 Place** | Location notes, spatial coordinates, and connected historical records. |
| **📚 Source & Box** | Source metadata, record inventory lists, and all attached document files. |
| **📄 Record** | High-res attachments, OCR transcriptions, captions, and custom tags. |
| **📝 Topic** | Full narrative essay, inline image cards, and auto-formatted GEDCOM references. |

---

## Export Formats & Full Backups

Choose the output structure that best fits your workflow, from single-topic exports to complete system backups:

| Format | Output Structure | Ideal Use Case |
| :--- | :--- | :--- |
| **Markdown Bundle** | Generates clean `.md` text notes alongside an `attachments/` folder for images and media. | Porting narrative notes into tools like Obsidian or publishing to personal blogs. |
| **PDF Document** | A single, self-contained PDF compiling text, embedded media, and reference citations. | Printing physical reports or emailing formatted dossiers to family members. |
| **Media Only** | Extracts and zips raw media attachment files without accompanying note text. | Creating quick photo backups or sharing raw scans with relatives. |
| **Full Archive Backup** *(JSON + Files)* | Exports a complete structured JSON representation of your entire database alongside all raw media assets. | Local backup restoration, system migration, or custom data analysis. |

---

## 🚀 Export Roadmap

* **Relative Links in Markdown:** Auto-generating standard relative links (e.g., `![Photo](./attachments/photo1.jpg)`) in Markdown exports for seamless rendering in Obsidian, Logseq, and static site generators.
* **GEDCOM Family Tree Export (`.ged`):** Native export of structured genealogical data into standard GEDCOM files for importing into primary genealogy software.
